# Isabelle Corine

Página estática da psicóloga Isabelle Corine, em Natal/RN. Identidade oficial: creme, bege, caramelo e marrom, com a logo em `logo/` e as fotos em `fotos/1000` e `fotos/2000`.

## Ver localmente

```bash
python3 -m http.server 8741
```

Abra `http://127.0.0.1:8741`.

## GitHub Pages

Publique a raiz do repositório. O arquivo `.nojekyll` impede o processamento do Jekyll. Os caminhos de CSS, script, logo e fotos são relativos, então a página também funciona em um subcaminho como `/nome-do-repositorio/`.
